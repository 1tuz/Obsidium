# Просмотр PDF

PDF открывается в обычной вкладке рабочей области и остаётся привязанным к файлу в дереве. Вкладка сохраняется в SQLite через существующий документный идентификатор: эта запись нужна для восстановления относительного пути после перезапуска, но PDF не загружается в редактор текста и не получает состояние курсора.

Просмотрщик загружается отдельным чанком только при открытии PDF и использует локальный PDF.js с локальным worker-файлом. Файл читается через Tauri asset URL, без отправки содержимого во внешнюю сеть. Страница подгоняется по ширине, а кнопки меняют страницу и масштаб.

Одновременно рендерится одна страница. Это ограничивает память для длинных документов и освобождает предыдущую задачу рендеринга при перелистывании или закрытии вкладки. Ошибка загрузки или разбора PDF отображается внутри вкладки; исходный файл не изменяется.
