# Workflow разработки Aquilum

## Два режима разработки

### 1. `npm run dev` — только фронтенд (браузер)
```bash
cd aquilum-app
npm run dev
```
- Открывает **http://localhost:1420/** в браузере
- **Hot Module Replacement (HMR)** — изменения в React/CSS применяются мгновенно
- Не работают Tauri-команды (Rust-функции), но весь UI доступен
- **Использовать для:** вёрстки, компонентов, стилей, логики UI

### 2. `npm run tauri dev` — полное приложение (окно)
```bash
cd aquilum-app
npm run tauri dev
```
- Открывает **нативное окно приложения**
- Внутри автоматически запускается Vite dev-сервер с HMR
- **Фронтенд** — hot reload (мгновенно)
- **Rust-бэкенд** — при изменении .rs файлов Cargo перекомпилирует (~3-10 сек)
- Работают ВСЕ функции: файловая система, Tauri-команды, системные API
- **Использовать для:** тестирования Tauri-команд, работы с файлами

### Рекомендуемый подход
```
1. Кодишь UI → npm run dev (в браузере, мгновенный HMR)
2. Нужно проверить Rust → npm run tauri dev (нативное окно)
3. Готов к релизу → npm run release (автосборка через GitHub Actions)
```

## Горячая перезагрузка (HMR)

**Что обновляется мгновенно:**
- `.tsx` / `.ts` файлы — React-компоненты перерисовываются
- `.css` файлы — стили применяются без перезагрузки
- `.json` файлы (переводы) — требуют перезагрузку (F5)

## Команды

| Команда | Что делает | Когда использовать |
|---------|-----------|-------------------|
| `npm run dev` | Vite dev-сервер + HMR | Разработка UI |
| `npm run tauri dev` | Полное приложение с HMR | Тест Tauri-функций |
| `npm run build` | Собрать фронтенд в `.artifacts/dist` | Проверка TypeScript |
| `npm run release` | Автосборка через GitHub Actions | Релиз |
| `npm run release:local` | Локальная сборка Windows | Проверка release-бинарника |

> **Безопасно:** все `npm run tauri …` идут через `scripts/tauri.ps1`.
> См. [[build-artifacts-separation]].

## Важно

- **НЕ нужно** запускать `npm run build` каждый раз — это только для финальной сборки
- **НЕ нужно** перезапускать dev-сервер при изменении файлов — HMR делает это автоматически
- Единственный случай для перезапуска — изменение `vite.config.ts` или `package.json`
