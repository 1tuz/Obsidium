# Панель форматирования редактора

Встроенная панель редактирует Markdown через существующие команды CodeMirror, форматирование таблиц и минимальные изменения текста. Настройки панели хранятся вместе с `AppConfig` в `settings.json`, чтобы одинаково работать в dev и установленной версии.

Положение `top` показывает панель над редактором. Положение `selection` показывает её рядом с выделением и пересчитывает координаты после изменения выделения, прокрутки и размера окна. Панель скрывается для неактивной вкладки, режима истории и пустого выделения.

Настройки встроенных функций находятся в разделе «Встроенные плагины». Kanban переключатель отключён, пока представление Kanban отсутствует.

Текстовые действия используют `toolbarMarkdown.ts`: inline-разметка сохраняет выделение, а блочные команды обрабатывают только затронутые строки. Изменения идут через транзакции CodeMirror, чтобы оставаться в истории редактора и Yjs-документа.
