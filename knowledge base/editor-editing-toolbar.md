# Панель форматирования редактора

Встроенная панель редактирует Markdown через команды CodeMirror, форматирование таблиц и минимальные изменения текста. Её положение и включение хранятся вместе с `AppConfig` в `settings.json`. Панель включает заголовки H1–H6, выделение текста, ссылки, изображения, списки, цитаты, таблицы, блоки кода и разделители. Изображение вставляется как Markdown-ссылка с выделенным текстом в качестве alt-текста; файлы и изображения также можно добавить существующей вставкой.

Положение `top` показывает компактную панель по ширине области документа. Положение `selection` показывает её рядом с выделением и пересчитывает координаты после изменения выделения, прокрутки и размера окна. Панель скрывается для неактивной вкладки, режима истории и пустого выделения.

Переключатель в панели заметки включает режимы чтения и редактирования. Режим чтения оставляет тот же CodeMirror/Yjs документ, но запрещает ввод и команды, скрывает панель форматирования и показывает Markdown без синтаксических маркеров. Это сохраняет виджеты и внешние обновления документа без второго renderer. При переходе к другой заметке режим сбрасывается на редактирование; версии истории остаются только для чтения.

Настройки встроенных функций находятся в разделе «Встроенные плагины». Переключатель Kanban включает панель досок и команды управления `.base`.

Текстовые действия используют `toolbarMarkdown.ts`: inline-разметка сохраняет выделение, а блочные команды обрабатывают только затронутые строки. Изменения идут через транзакции CodeMirror, чтобы оставаться в истории редактора и Yjs-документа.
