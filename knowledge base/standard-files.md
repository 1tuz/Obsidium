# Просмотр стандартных файлов в рабочей области

## Форматы и открытие

Markdown остаётся документом Yjs с историей, ссылками и поисковым индексом.
Обычные текстовые файлы (`yaml`, `yml`, `json`, `toml`, `txt`, `csv`, `xml`, `ini`,
`log`, `js`, `ts`, `py`, `rs`, `sh`, `ps1`, `sql`, `html`, `css`) открываются отдельным
CodeMirror-редактором. Языковая поддержка берётся из `@codemirror/language-data` и
загружается по расширению. Изображения и остальные бинарные вложения редактором не открываются.

PDF передаётся системному приложению по умолчанию через Tauri opener. Это использует
встроенный в ОС просмотрщик и не добавляет PDF.js в размер приложения.

## Сохранение текста

Текстовые файлы читаются через `read_file_snapshot` и сохраняются через
`write_file_atomic` с хешем снимка. Автосохранение откладывается на 700 мс и сериализуется:
каждая запись использует хеш результата предыдущей. Если файл изменился извне раньше записи,
проверка хеша отклоняет сохранение, редактор сохраняет буфер и предлагает перечитать файл.
Перечитывание заменяет локальный буфер актуальной версией с диска.

Этот редактор не подключает файлы к Yjs, истории заметок, поиску и ссылкам Markdown.
Не добавляйте эти форматы в `is_markdown`: эти подсистемы рассчитывают на Markdown и
работают только с заметками. Списки расширений в `fileGateway.ts` и `workspace.rs` должны
оставаться согласованными; Markdown распознаётся отдельной проверкой.
