## CLI

Workspace Cargo включает `obsidium-app/cli`: бинарник `obsidium` открывает `Core` без Tauri и
WebView. Он поддерживает список баз, поиск, чтение и запись заметок, backlinks и историю. Базу
можно указать через `--workspace PATH` или `OBSIDIUM_WORKSPACE`; большинство команд принимает
`--json`.

Записи заметок проходят через `files::gate`, поэтому проверяются хэш, история и обновление поиска.
Для MCP stdio у GUI-бинарника `--mcp-stdio` открывает такой же отдельный headless `Core`. Флаг
`--mcp-stdio-bridge` сохраняет прежний режим: передаёт запросы запущенному GUI через HTTP.

Headless-процессы хранят свои SQLite-состояния в подпапках `headless-cli` и `headless-mcp` внутри
`app_data_dir`. Настройки и известные базы копируются из основного профиля; состояние GUI не
разделяется с этими процессами. `OBSIDIUM_DATA_DIR` позволяет указать корень данных явно.

## Транзакционная правка заметок через MCP

`preview_transaction` проверяет до 50 существующих заметок и возвращает хэши до и после без записи.
`apply_transaction` повторно проверяет ожидаемые хэши и записывает изменения через общий шлюз.
Ответ содержит `transactionId`; `rollback_transaction` принимает его, если ни одна заметка после
применения не менялась. Запись транзакции находится в `.aquilum/transactions` внутри базы.

Запись нескольких файлов не является одной файловой операцией: инструмент применяет правки по
очереди и отменяет уже выполненные, если следующий файл конфликтует или не записывается. Если
автоматическая отмена не проходит, ошибка явно сообщает о неполном откате. Откат транзакции сначала
проверяет все хэши, поэтому внешняя правка любой затронутой заметки отменяет весь запрос на откат.

## Версии протокола MCP

Сервер сохраняет совместимость с `initialize` старых клиентов и также принимает stateless-контракт
с `server/discover` и версией `2026-07-28` в `_meta`. Неизвестная версия возвращает список
поддерживаемых версий. Ответы нового контракта помечены как завершённые и содержат сведения о
сервере. Для discovery и списка инструментов указан частный кэш со сроком жизни ноль.
