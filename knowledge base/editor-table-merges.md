## Модель

`TableModel` / `MergeRange` — `aquilum-app/src/components/Editor/extensions/tables/model.ts`.

```ts
interface TableModel {
  cells: string[][];
  merges: MergeRange[];
  aligns: TableAlign[];
  rowHeights: number[];
  colWidths: number[];
}

interface MergeRange {
  top: number;
  left: number;
  bottom: number;
  right: number;
}
```

Координаты нулевые. `row: 0` — заголовочный ряд GFM. `left/top` — якорь
объединения, `right/bottom` включительны.

Пример B2:C3:

```ts
{ top: 1, left: 1, bottom: 2, right: 2 }
```

Инварианты:

1. Все строки имеют столько ячеек, сколько столбцов в `aligns`.
2. Merge-регион всегда внутри таблицы и площадью ≥ 2 ячеек.
3. Два merge не пересекаются и не вложены друг в друга.
4. Значение области принадлежит верхнему левому якорю; внутренние позиции
   синхронизированы с ним для сериализации, но не редактируются отдельно.
5. Любое обращение к покрытой позиции идёт через `anchorAt`.
6. Массив merge стабильно упорядочен: сверху вниз, затем слева направо.

`mergeCells` принимает только полный прямоугольник и сам его не расширяет.
UI сначала применяет `expandSelection`, затем передаёт модели уже корректный
диапазон — так один merge не может случайно изменить другой.

## Объединение

1. Выделите прямоугольник drag-ом, Shift+click или strip-ами.
2. ПКМ → «Объединить ячейки».

Сохраняется только значение верхней левой ячейки итогового прямоугольника;
остальные очищаются (как в Excel).

Если выделение полностью включает один или несколько существующих merge, они
заменяются одним итоговым регионом. Незатронутые merge не меняются. Если
выделение касается только части merge, UI расширит его до полного региона до
вызова команды.

## Разъединение

ПКМ по любой видимой части объединения → «Разъединить ячейки».

- удаляется только найденный merge-регион;
- верхняя левая ячейка сохраняет значение;
- остальные ячейки региона становятся самостоятельными пустыми;
- соседние и диагональные объединения не меняются.

Выбор одной ячейки внутри merge визуально раскрывает весь merge. Команда
всегда действует на один регион.

## Сценарий: расширение существующего merge

Исходная таблица содержит B2:C2:

```text
      A          B           C        D
2   API       План                       QA
3   UI        dev         review       OK
```

```ts
merges: [{ top: 1, left: 1, bottom: 1, right: 2 }]
```

Выделение B2:D3 полностью включает B2:C2. После «Объединить»:

```ts
merges: [{ top: 1, left: 1, bottom: 2, right: 3 }]
```

## Сценарий: независимые блоки

```ts
merges: [
  { top: 1, left: 0, bottom: 1, right: 1 },
  { top: 2, left: 2, bottom: 3, right: 3 },
]
```

Разъединение второго оставит первый как был. Объединение A3:B4 не трогает
оба существующих региона, если диапазоны не пересекаются.

## Сложные комбинации

### Три независимых merge и очистка диапазона

```md
| Площадка | Владелец | Сервис | Канал | Статус |
| --- | --- | --- | --- | --- |
| EU |  | Переключение |  |  |
| US | Команда A | Incident |  |  |
| APAC | Команда B | ^^ | ^^ | Pending |
| LatAm | Команда C | Docs | Help | Draft |
<!--q-table:{"merges":[[1,0,1,1],[1,2,1,4],[2,2,3,3]]}-->
```

Три региона: `A2:B2`, `C2:E2`, `C3:D4`. Del по A2:E4 очищает якоря, но
сохраняет геометрию merge. Unmerge C3:D4 трогает только этот регион.

### Расширение через касание merge

Тяга от B2 до C3 при существующем A2:B2 → итоговый диапазон A2:C3; значение
якоря — из A2. Остальные значения не склеиваются автоматически.

### Разъединение среди соседних merge

ПКМ внутри одного региона никогда не «проходит» по похожим соседним merge.

### Удаление строки внутри span

Каждый `MergeRange` преобразуется отдельно (сдвиг / сжатие span). Значения
якорей сохраняются. См. также [[editor-table-structure]].

## Связь со strip-reorder

Expand при выделении strip = блок для drag. Нельзя бросить столбец/строку в
щель внутри чужого merge — см.
[[editor-table-strip-reorder]].
