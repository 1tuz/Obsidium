# Канбан-представление Bases

## Связанные документы

- [[dataview-queries]] — запросы и поля заметок.
- [[frontmatter-field-index]] — индексируемые поля frontmatter.
- [[notes-gate]] — запись через общий шлюз.

Канбан — один из типов представления в `.base`. Поле `groupBy.property` задаёт колонки, а
`groupOrder` задаёт их порядок и сохраняет пустые колонки. Если `groupBy` отсутствует, используется
`status`; значения, которых нет в `groupOrder`, сортируются по алфавиту с учётом чисел, направление
берётся из `groupBy.direction`.

Перетаскивание меняет значение свойства заметки во frontmatter. Перед записью BaseView перечитывает
снимок файла и передаёт его хэш в `writeFileAtomic`, поэтому конфликт с внешним изменением не
перезаписывает файл. Поля `file.*` и `formula.*` только для чтения и не принимают перетаскивание.

Моделью остаётся `.md` и файл `.base`; отдельная база данных для доски не создаётся.
