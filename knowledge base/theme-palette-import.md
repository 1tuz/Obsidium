# Импорт пользовательских палитр

Чтобы добавить палитру, откройте **Настройки → Отображение**, нажмите **Импортировать палитру** рядом с выбором палитры и выберите файл. Поддерживаются `.tokens`, `.tokens.json` и `.json` с ограниченным подмножеством формата DTCG 2025.10. Название в списке берётся из имени файла. Приложение разбирает файл локально и хранит импортированную палитру вместе с `AppConfig` в `settings.json` внутри `app_data_dir`. Палитра доступна после перезапуска и в dev/release окружениях с общим каталогом данных.

Файл должен содержать группы `light` и `dark`. Каждая группа обязана включать токены `background`, `text` и `accent` в форме DTCG цвета:

```json
{
  "light": {
    "background": { "$type": "color", "$value": { "colorSpace": "srgb", "components": [1, 1, 1] } },
    "text": { "$type": "color", "$value": { "colorSpace": "srgb", "components": [0.1, 0.1, 0.1] } },
    "accent": { "$type": "color", "$value": { "colorSpace": "srgb", "components": [0.08, 0.44, 0.92] } }
  },
  "dark": {
    "background": { "$type": "color", "$value": { "colorSpace": "srgb", "components": [0.04, 0.05, 0.07] } },
    "text": { "$type": "color", "$value": { "colorSpace": "srgb", "components": [0.95, 0.96, 0.98] } },
    "accent": { "$type": "color", "$value": { "colorSpace": "srgb", "components": [0.34, 0.58, 0.9] } }
  }
}
```

Компоненты sRGB задаются числами от 0 до 1. Поддерживаются только непрозрачные цвета: alpha может отсутствовать либо быть равна 1. Пространства Display-P3, ссылки на токены, составные значения, дополнительные роли и другие части формата DTCG не разбираются. Название берётся из имени файла, а surfaces и границы интерфейс выводит из трёх импортированных ролей. Максимальный размер файла — 64 KiB. Ошибка разбора не меняет список палитр и текущую тему.

Идентификатор строится стабильным хэшем нормализованного имени файла, поэтому поддерживаются и кириллические имена. Повторный импорт с тем же именем заменяет пользовательскую палитру с этим идентификатором. Совпадение с идентификатором встроенной палитры получает числовой суффикс. Настройки сериализуются атомарной записью существующего settings manager.
