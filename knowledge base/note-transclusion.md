# Вложение заметок

Строка вида `![[Заметка]]` заменяется блочным виджетом в live preview, пока каретка не стоит на
этой строке. `![[Папка/Заметка#Заголовок]]` показывает выбранный раздел до следующего заголовка того
же или более высокого уровня. Frontmatter в теле вложения скрыт.

Виджет разрешает путь через существующий wiki resolver и читает снимок файла. Текст отображается во
вложенном read-only CodeMirror без открытия сессии документа и без добавления в поисковый индекс.
Содержимое загружается при создании виджета; событие изменения Markdown в активном vault обновляет
вложение. Кнопка заголовка открывает исходную заметку.

Вложенные `![[...]]` раскрываются повторно. Цепочка путей передаётся вложенным виджетам, а повторный
путь заменяется сообщением о цикле, поэтому `A → B → A` не запускает бесконечный рендер. Встроенные
заметки доступны только для чтения; Dataview и другие plugin blocks не исполняются. Неизвестный
Markdown сохраняется в исходном файле.
