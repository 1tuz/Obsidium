# Theme Engine

`ui.appearance` выбирает `system`, `light` или `dark`; `ui.palette` выбирает цветовую схему
независимо от режима. Реестр в `src/modules/theme/index.ts` связывает каждую палитру с CSS
переменными светлого и тёмного вариантов. `data-appearance`, `data-palette` и классы
`theme-light` / `theme-dark` выставляются на `documentElement`, включая базовые переменные Obsidian.

Настройки применяются к DOM сразу и сохраняются через общий `updateConfig`. Старое поле `ui.theme`
читается Rust через serde alias для `appearance`; при следующем сохранении записывается новая схема.
Неизвестный id палитры отображается как `obsidium`.

Кнопка в titlebar меняет фактически отображаемый режим на противоположный и сохраняет его как явный
`appearance`. Поэтому нажатие при режиме `system` отключает системное следование до следующего выбора
`system` в настройках.

`ui.motion` принимает `system`, `on` и `off`. CSS учитывает `prefers-reduced-motion`; графический
`FrameClock` не ставит следующий кадр при выключенной анимации, а редактор не запускает таймер
появления внешних вставок. Редакторский таймер также останавливается при смене настройки или системной
предпочтительности.

Палитры меняют основные фоновые, текстовые и accent-токены через общую CSS-семантику; компоненты не
получают копии CSS для каждой палитры. В `src/modules/theme/index.test.ts` проверены реестр, применение
режима и совместимые классы; отдельный тест `App.test.tsx` проверяет сохранение из titlebar.
