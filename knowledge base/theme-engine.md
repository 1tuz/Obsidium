# Theme Engine

`ui.appearance` выбирает `system`, `light` или `dark`; `ui.palette` выбирает цветовую схему
независимо от режима. Реестр в `src/modules/theme/index.ts` связывает каждую из 58 палитр с CSS
переменными светлого и тёмного вариантов. `data-appearance`, `data-palette` и классы
`theme-light` / `theme-dark` выставляются на `documentElement`, включая базовые переменные Obsidian.

`ui.accentMode` выбирает источник accent: `palette` (по умолчанию) или `custom` (`primaryColor`).
При миграции прежние стандартные цвета `#1471EB` и `#D357FE` остаются в `primaryColor`, но режим
переключается на `palette`, чтобы старое значение не перекрывало выбранную тему. Другие сохранённые
custom-цвета остаются активными. Поле цвета показывается только при выборе `custom`.

Настройки применяются к DOM сразу и сохраняются через общий `updateConfig`. Старое поле `ui.theme`
читается Rust через serde alias для `appearance`; при следующем сохранении записывается новая схема.
Неизвестный id палитры отображается как `obsidium`.

Переключатель темы находится внизу левого сайдбара рядом с настройками. Он меняет фактически
отображаемый режим на противоположный и сохраняет его как явный `appearance`. Поэтому нажатие при
режиме `system` отключает системное следование до следующего выбора `system` в настройках.

При включённом `ui.motion` быстрый переключатель темы раскрывает новую тему кругом от нажатой кнопки
через View Transition API. При выключенной анимации, системном `prefers-reduced-motion` или отсутствии
API тема применяется сразу. Команда в палитре команд также переключает тему без геометрического
источника анимации.

`ui.motion` принимает `system`, `on` и `off`; новое значение по умолчанию — `off`. Выбор сохраняется
в общем `settings.json`. В режиме `off` CSS полностью отключает animation и transition, графический
`FrameClock` не ставит следующий кадр, а редактор не запускает таймер появления внешних вставок.
Режим `system` уважает `prefers-reduced-motion`; редакторский таймер останавливается при смене
настройки или системной предпочтительности.

Настройки открывают единый алфавитный каталог карточек отдельным диалогом. Миниатюра каждой карточки строится из тех же
фоновых, текстовых и accent-токенов и реагирует на текущий режим. CSS-переменные палитр имеют уникальные
имена и доступны на `:root` одновременно, поэтому миниатюры читают цвета всех тем без переключения
активной темы. `palette-semantic.css` связывает общие токены поверхностей, текста, границ, вкладок,
редактора, диалогов и графа с активной палитрой; состояния hover, active и focus используют эти же
токены. Цвета ссылок и текста акцентных кнопок вычисляются с контрастом WCAG AA; исходный акцент
палитры остаётся фоном акцентных элементов. Оттенки обычного, вторичного, приглушённого и выключенного
текста используют один контрастный цвет. Компоненты не получают копии CSS для каждой палитры.
Settings sections остаются отдельными lazy chunks; их размер сведён в [[bundle-size-report]].
`src/modules/theme/index.test.ts` проверяет все 116 сочетаний палитры и режима, контраст текста,
ссылок и акцентных кнопок, переключение, fallback и привязку семантических токенов; отдельный тест
`App.test.tsx` проверяет сохранение из titlebar.

Исходники и лицензии новых палитр описаны в [[theme-palette-sources]]. Оригинальные тёмные HEX
сохранены; светлые варианты RehamVim/osyx закреплены HEX-значениями, полученными из их прежнего
`color-mix`, чтобы проверить контраст каждого из 116 режимов без зависимости от браузерного вычисления.
Solarized Light использует более тёмный оттенок текста, сохраняя исходную тёплую поверхность и синий
акцент.

Фон страницы редактора использует активный canvas, смешанный с контрастным текстом на 16% в обоих
режимах, чтобы длинный текст не лежал на чистом почти чёрном или белом фоне.

Canvas графа держит разобранные цвета в GPU renderer, поэтому он слушает изменения атрибутов
`data-theme`, `data-palette` и `style`: последнее обновляет граф при смене пользовательского accent.
